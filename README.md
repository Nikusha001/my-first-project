# CIAO ENERGY - 3D WebGL Showcase 🚀

ეს პროექტი წარმოადგენს TikTok ვიდეოში ნაჩვენები **Ciao Energy**-ს (`ciaoenergy.com`) ოფიციალური 3D ინტერაქტიული ვებსაიტის ზუსტ კლონს და იმპლემენტაციას Three.js-ის, WebGL-ისა და თანამედროვე JavaScript-ის გამოყენებით.

---

## ✨ რა ფუნქციონალია ჩაშენებული:

1. **3D მოდელები და რეალისტური მასალები (PBR Materials)**:
   - ენერგეტიკული სასმელის 3D ქილა (`can.glb`) მეტალის ამრეკლავი ალუმინის ზედაპირით (`MeshStandardMaterial`, `metalness: 0.95`, `roughness: 0.18`).
   - ზედა მფრინავი თეფში (UFO Saucer / Beam Emitter) და ქვედა პედესტალი (`base.glb`).
   - 6 სხვადასხვა გემოს უმაღლესი ხარისხის ორიგინალი ტექსტურა.

2. **3D კარუსელი და ფიზიკა (Interactive 3D Carousel)**:
   - მაუსით Drag / სვაიპის ან თაჩის მხარდაჭერა.
   - ისრებით ნავიგაცია (`<` და `>`).
   - გვერდითა ქილებზე დაკლიკებით ცენტრში გადმოტანა (Raycasting).
   - Mouse Parallax ეფექტი — მაუსის მოძრაობაზე სცენისა და კამერის რბილი დახრა.
   - მცურავი ლევიტაციის ანიმაცია (Hover levitation sine wave).

3. **დინამიური განათება და ატმოსფერო**:
   - გემოს შეცვლისას ფონის რადიალური გრადიენტის ავტომატური ადაპტაცია (`Double Litchi`, `Coco Citron Vert`, `Kiwi Concombre`, `Pêche Blanche`, `Pomme Rhubarbe`, `Abricot Framboise`).
   - Three.js PointLight & SpotLight რეფლექსები.
   - ნაწილაკების სისტემა (Ambient Energy Particles).

4. **ხმოვანი ეფექტები (Sound FX)**:
   - Web Audio API ინტეგრაცია — გადართვისას "Swoosh" და ღილაკებზე "Click" ხმები.
   - ხმის ჩართვა/გამორთვა (SOUND ON / OFF).
